ResQ Meet Authorization

ResQ needs a Google Refresh Token to automatically create Google Meet spaces on behalf of doctors. Use this utility to authorize and obtain it securely.

Step 1: Configure Google Console
Ensure your Google Web Application credentials have the following Authorized Redirect URI configured:

https://iderhuahuqbffhzjkpfa.supabase.co/functions/v1/create-meet-space/callback
Step 2: Set Edge Function Secrets
Ensure GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET are set in your Supabase Edge Function Secrets.
